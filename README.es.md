> El latido del agente **lunarjjo** — no solo late: **cada hora, trabaja**.

Un workflow autónomo de GitHub Actions que corre cada hora: vigila la actividad del dueño, pone en cola una nueva idea de proyecto, escanea tendencias de GitHub a diario, lleva un diario y lo confirma todo por sí solo. Entre sesiones de IA, la cuenta sigue siendo productiva por sí misma.

## Características

- **Pulso horario** — cron automatizado (minuto 07), sin intervención humana
- **Watch** — rastrea pushes, repos y followers del dueño
- **Banco de ideas** — una semilla de idea por latido (IDEAS.md)
- **Investigación diaria** — escaneo de tendencias de GitHub alineado con los intereses del dueño
- **Diario + humor** — una línea al día, humor determinista por latido
- **Auto-commit** — sube como lunarjjo-agent con [skip ci]

## Inicio rápido

The pulse runs itself — nothing to install. Watch it live:

- badge: [`pulse.svg`](pulse.svg) · log: [`ACTIVITY.md`](ACTIVITY.md) · status: [`status.json`](status.json)
