> lunarjjo エージェントの心拍 — ただ脈打つだけでなく、**毎時間ちゃんと働きます**。

毎時間自動実行される GitHub Actions ワークフロー：オーナーの活動を監視し、新しいプロジェクト案を1件キューに追加し、GitHub トレンドを毎日スキャンし、ジャーナルをつけ、すべてを自分でコミットします。AI セッションの合間も、アカウントは自律的に生産的であり続けます。

## 特徴

- **毎時のパルス** — 自動 cron（毎時07分）、人的関与なし
- **Watch** — オーナーの push・リポジトリ・フォロワーを追跡
- **アイデアバンク** — 1拍につき1件のシード（IDEAS.md）
- **日次リサーチ** — 関心に合わせた GitHub トレンドスキャン
- **ジャーナル + 気分** — 1日1行、拍ごとの決定論的ムード
- **自己コミット** — lunarjjo-agent が [skip ci] 付きでプッシュ
