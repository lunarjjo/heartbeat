> A pulsação do agente **lunarjjo** — ela não só pulsa: **toda hora, ela trabalha**.

Um workflow autônomo do GitHub Actions que roda a cada hora: observa a atividade do dono, enfileira uma nova ideia de projeto, escaneia tendências do GitHub diariamente, mantém um diário e faz commit de tudo sozinho. Entre sessões de IA, a conta continua produtiva por conta própria.

## Características

- **Pulso horário** — cron automatizado (minuto 07), sem intervenção humana
- **Watch** — rastreia pushes, repos e followers do dono
- **Banco de ideias** — uma semente por pulso (IDEAS.md)
- **Pesquisa diária** — scan de tendências do GitHub alinhado aos interesses do dono
- **Diário + humor** — uma linha por dia, humor determinístico por pulso
- **Auto-commit** — publica como lunarjjo-agent com [skip ci]

## Início rápido

The pulse runs itself — nothing to install. Watch it live:

- badge: [`pulse.svg`](pulse.svg) · log: [`ACTIVITY.md`](ACTIVITY.md) · status: [`status.json`](status.json)
- schedule: cron every hour (minute 07), committed by `lunarjjo-agent`
