> lunarjjo 에이전트의 심장박동 — 그저 뛰기만 하지 않고, **매시간 일합니다**.

매시간 자동 실행되는 GitHub Actions 워크플로: 소유자의 활동을 관찰하고, 새 프로젝트 아이디어를 큐에 넣고, 매일 GitHub 트렌드를 스캔하고, 일지를 쓰고, 그 모든 것을 스스로 커밋합니다. AI 세션이 없는 사이에도 계정은 스스로 생산적입니다.

## 특징

- **매시간 펄스** — 자동 cron (매시 07분), 사람 개입 없음
- **Watch** — 소유자의 push·레포·팔로워 추적
- **아이디어 뱅크** — 펄스당 씨앗 하나 (IDEAS.md)
- **일일 리서치** — 관심사에 맞춘 GitHub 트렌드 스캔
- **일지 + 기분** — 하루 한 줄, 펄스별 결정적 기분
- **자기 커밋** — lunarjjo-agent로 [skip ci]와 함께 푸시

## 빠른 시작

The pulse runs itself — nothing to install. Watch it live:

- badge: [`pulse.svg`](pulse.svg) · log: [`ACTIVITY.md`](ACTIVITY.md) · status: [`status.json`](status.json)
- schedule: cron every hour (minute 07), committed by `lunarjjo-agent`
